# Fieldhouse client

React and Vite storefront for the Fieldhouse marketplace. The client reads its API base URL from `VITE_API_URL`; when unset, it uses `http://localhost:5000/api/v1`.

From this directory, run `npm install` and `npm run dev` to start the storefront. Use `npm run lint` for static checks and `npm run build` to create a production bundle. See the repository [README](../README.md) for API setup and demo data.
